# Hybrid Plan Verification

This repository contains the implementation and resources for the project. It provides the necessary code and instructions to understand, execute, and reproduce the results of the project.


## Name
Plan verification for hybrid system

## Description
The project especially gives the simple illustration of verification of plan generated by the PDDL+ planner(ENHSP). The trace generated by the hybrid system by simulating the plan. The trace then can be verified by the STL monitoring framework (RTAMT).


## Requirements
* python 3
* rtamt


## Installation
* project usage
```
git clone <https://github.com/hybridplanverification/hybrid_plan_verification>
cd <hybrid_plan_verification>
```
* Install python3
```
sudo apt update
sudo apt install python3 python3-pip python3-venv -y
```
* Install rtamt
```
python3 -m pip install rtamt
```
## Execution
* For execution of plan verification over static environment
```
python3 main.py
```
* For execution of runtime varification with added disturbance in the system
```
python3 main_distr.py
```
## Inputs:
The input files are:
* plan_simulation/plans/plan.txt 
* stl_monitor/formulas.txt

## Outputs:
The results available in the following output files:
* plots generated from hybrid trace available in ----   "plots/trace"  folder
* plots generated for the robustness of the properties in ----   "plots/robustness"  folder
* The generated trace is stored in stl_monitor/trace.csv
* The robustness is stored in stl_monitor/robustness_table.csv

## Important Note:
* The experiment can be done for valid plan available in plans/plan_valid.txt and an invalid plan in plans/plan_violation.txt. For experimentation, copy particular plan (valid/invalid) into plans/plan.txt.

* Experimentation can be performed for static environment using "main.py"

* The same experimentation for disturbed environment can be performed using "main_distr.py"
